# GroupedStorage 带宽分配缓存验证（2026-11-03）

本次仅增加当前活跃读集合的分配缓存。原始盘内分配和共享链路缩放后分配均可复用。新读取加入、读取组完成或启动等待结束时刷新。当前实现按全局活跃集合失效，没有增加按盘增量更新、事件堆或后台推进。

配置在实例生命周期内固定。保留原分配顺序、ready 的 1e-12 秒容差、字节累加顺序及原完成阈值。普通查询仍通过原服务锁并按墙钟推进。

## 固定读取记录对拍

使用上一轮 Mooncake ABC 100 GB/s、α=0.1 的 25,740 次正式逐层读取；固定其提交时间、块数、需求、启动等待和盘放置。前后各重放三次，顺序 before/cached/cached/before/before/cached。每次读取完成时间和各盘已传输字节数逐位一致，时间推进调用次数也一致。与原运行记录核对最大完成时间偏差小于 1e-7 秒。

重放程序运行时间中位数：7.704 秒 → 3.773 秒，减少 51.0%。这是离线处理时间，不是请求完成时间。

## 完整性与限制

- 342 项完整单元测试通过。新增测试覆盖重复查询复用、提交/完成刷新、延迟就绪、共享链路及随机四盘 counted 事件轨迹；后者与未缓存计算逐位一致。
- 每轮正式读取均为 539571462144 B。输入、模型公式、层屏障、EDF、路由、配额归零、RPC 排空和进程退出均由原入口验收。
- 计算占比为名义模型时间 /（实例数 × 完成窗口），不是硬件利用率。无在途 IO 的比例包括正常计算、到达间隔与尾部，不能全部归因为 RPC。
- 实际进程栈会重新组批和路由，前后 batch 不固定；固定提交时间的精确对拍与实际运行收益分开统计。
- 每个条件仅两次，当前结果用于定位实现开销，不提供置信区间，也不证明其他负载和硬件上的稳定收益。没有重跑原六负载三十组矩阵。
