# MiniMax total16：50k 拟合与范围外推

当前版本 `prefill50k_total16_v2`，模型 SHA256：
`48776fc742ba30edd6715219cff9fb9891104c55c5cc8e45df3a3f292857e1aa`。

本版本沿用 2026-11-13 的 189 个训练点、51 个独立验证点和已冻结的 10 个岭回归系数。没有新增高 H 测量，也没有把验证点加入训练。模型预测 TP=2、batch=1 的 MiniMax 量化模型 16 层设备执行时间，不包含分词、排队和 OD I/O。

## 范围策略

- 接受整数 H>=0、U>=1、H+U+1<=98000。
- U>50000 按 50000 拆分；后一个块的 H 增加已计算的 token 数。此预算沿用当前 worker 配置，修改执行预算后需要重新检查估时语义。
- 原测量包络保持不变：H<=47104 时 U<=50000；47104<H<=50048 时 U<=40960；50048<H<=61440 时 U<=11441。
- 包络内使用冻结公式，240 点的预测与 v1 逐点一致。
- 包络外继续计算同一岭回归公式，不回退旧模型；source 为 `prefill50k_total16_v2_extrapolated`。
- H>61440 时增加下限：预测不低于同一 U 在 H=61440 的公式值。它是保守的人工约束，不是新增测量或重新训练的结果。
- 单块预测下限为 1 ms。现有 240 点不触发该下限。
- 组合多个块时，只要一个块使用外推，整条画像就标记为外推。`sim/reference_time.py` 保留此标记。

H=61440、U=256 的预测为 59.2335865273372 ms。H=90112、U=256 的外推预测约 65.832 ms。后者没有真机误差验证。

## 仿真接入

`python -m minimax_prefill 61440 256` 输出时间、拟合来源及模型 SHA256。
进程栈通过 `configs/minimax_native_ingress.json` 选用该模型。参考画像和实际模拟前向都使用该公式。
逐层模式将总时间等分为 16 层，表示仿真假设。运行和验证见上级 README 和 VALIDATION。
