# 归档复现说明

本目录是已完成实验的报告归档，不包含大型原始日志、依赖环境或原生二进制。

该历史报告未提供当前标准 dataset。现有配图和 CSV 可查看、复核；不承诺使用通用工具完整重绘。report_data/source_scripts 中的旧脚本仅作来源资料，可能依赖原工作区路径，不是本交付包的运行入口。

如需重新运行实验，先按 docs/实验分支使用说明.md 与 benchmark 对应的运行合同准备环境。export_only 或历史模型差异必须先处理，不能套用现行默认配置后声称复现了旧结果。

未随归档发布的资源：原始层日志、原始控制/RPC事件、运行依赖和原生构建。它们的旧位置及指纹保留在来源验证/provenance 内；仅有汇总表不能逐事件恢复原运行。
