# 格式与图表规范

## 文档排版

交付以 Markdown 为主，图片为独立 PNG。白底技术报告，无封面装饰、卡片或渐变。一个一级标题；二级章节从 0 编号；三级标题分工况。先结论，后证据。图就近嵌入相关章节，每图后接“**读法**：”。表格数字列右对齐，百分比通常保留 1 位小数，时间通常保留 1 位小数，其他精度随误差范围确定。重点结论或关键数值用粗体，不将整段加粗。

文档开头使用两列表格“项目｜约定”，包括：实验日与报告整理日、负载、请求形状、资源、比较方案、输入种子与重复、实验矩阵、汇总口径、轨迹图口径、SLO/TTFT 定义、执行边界、存储与配额、代码版本与数据来源。无关项可省略或替换；关键统计口径不能省略。

章节顺序：

0. 总判决：结论、相对基线的主要数值变化、条件、反例。比例差用“个百分点”，不与相对百分比混用。
1. 汇总表与 SLO 柱状图：按工况分别列出方案、总及分类 SLO、平均 TTFT、等待、makespan 等适用指标；补方案差异表。
2. 各方案 full-sort-ms 执行时间线：每个工况各一张完整图，必要时另加放大图及批次统计。
3. NPU 利用率分布与热力图：每个工况各一张箱线与热力图组合图，并给关键利用率表。设备类型按实际情况替换。
4. 存储带宽时序：各工况各一张按方案纵向排列的图，并列需求超订率、实际饱和率、平均带宽。
5. TTFT 累积分布 CDF：总体与分类分别画图，报告 p50/p95 和期限。
6. 机制解释、与前序或同源实验对照：指出受控变量、不可直接对比处和反例。
7. 计算模型与结论限制：区分模拟与实测、种子数与路由重复、模型假设与部署证据。
8. 附表：次要配置、消融或补充工况。有数据时填写。
9. 验证、数据与复现：检查结果、数据与脚本相对链接、复现方法、是否重跑实验。
10. 简要解读：可操作的解释与后续验证方向，不扩大证据范围。

## 固定配色

颜色按语义复用，不能把不同图中的相同颜色强制解释为同一对象。图例明确标注。

| 图型 / 对象 | 色值 | 含义 |
|---|---|---|
| 时间线 A / B / C | `#4C72B0` / `#DD8452` / `#55A868` | 各类纯计算 |
| 在线时间线 heavy / light | `#4C72B0` / `#DD8452` | 在线重读 / 轻读计算；不可由历史A/B/C猜测 |
| 时间线 mixed | `#9974A5` | 多类别共同计算；单类多请求仍用本类色 |
| 在线时间线 io / idle | `#C44E52` / `#C7C7C7` | 在途IO并集减去名义计算 / 其余空闲、排队与控制；不是纯依赖等待 / 无请求的直接证据 |
| 方案 immediate | `#888888` | 直接提交 |
| 方案 slack_only | `#C44E52` | 仅等待预算排序 |
| 方案 quota_fcfs | `#DD8452` | 配额+先到先服务 |
| 方案 tfs | `#55A868` | TFS |
| 汇总工况 C_A / C_B | `#6A9FDA` / `#2C5F9E` | 成组柱状图的浅蓝 / 深蓝 |
| 利用率箱体 / 均值 | `#9DC3E6`，alpha=0.8 / `#C44E52` | 浅蓝箱体 / 红色菱形均值；中位数黑线 |
| 利用率热力图 | `viridis` | 固定 0–100%，亮色表示高利用率 |
| 带宽 demand / actual | `#DD8452` / `#4C72B0` | 需求 / 实际速率 |
| 带宽上限 / 期限 | 黑色虚线 / `#444444` 点线 | 物理容量 / 期限参考 |

新方案沿用现有方案颜色；新增方案使用不冲突的颜色，并记录映射。方案顺序由实验设计决定，所有图表保持一致。不能为展示优势按指标分别重排方案。

历史ABC报告可保留业务分类配色，但图例须写明业务类别。研究在线重读时优先使用在线轻重图例；同一报告的SLO/CDF可以继续使用明确标注的历史业务分组，两套分类不能混用。

## 图形样式与布局

使用 Matplotlib，白底 PNG，160 dpi。中文字体优先 Arial Unicode MS，回退到能覆盖中文的字体；正文默认 10 pt，图标题 12 pt，图例 8–9 pt，密集设备编号可降为 6 pt。字体缺失时先解决字体再导出。浅网格 alpha≈0.14–0.22；图例放空白区。标题用“图N｜工况 + 内容”，副标题说明 seed、repeat 和配置。字号以最终 PNG 可读为准。

下列尺寸单位为英寸，沿用四方案原版；方案数、设备数或文字增多时增大画布，不挤压文字。

| 图型 | 尺寸 | 布局 |
|---|---|---|
| SLO 柱状图 | 11.8 × 6.2 | x=方案；同一方案不同工况并排；y=0–100% 左右，留标注空间 |
| full-sort-ms | 16.5 × 13.5 | 四方案上下四行，共享横轴；总图例置顶 |
| 利用率 | 14 × 5.3 | 左箱线、右热力图，宽度比 1:1.6 |
| 带宽 | 14.6 × 10.8 | 四方案上下四行，共享横纵轴 |
| 总体 CDF | 10.2 × 6 | 每方案一条曲线，图例含 p50/p95 |
| 分类 CDF | 15.5 × 4.7 | 三类横向三列，共享 y 轴；各类期限竖线 |

### 汇总柱状图

柱高对应主表相同统计口径。柱顶写数值，柱内可用白字标注分类 SLO。分类 SLO 是独立统计量，不是堆叠柱的高度组成。仅在确有多输入种子时画输入种子范围，明确最小/最大值不是置信区间；单输入种子不能伪造变异。其他实验若用置信区间，标明计算方法。

### full-sort-ms

时间单位 ms。每方案独立按设备首次执行 step 的时间排序，同刻以原设备编号排序；保留原编号。未执行设备置底并说明。排序只改变展示。所有方案在同一工况内共用覆盖最长运行的横轴；本方案完成虚线右侧的灰色仅为统一横轴补齐，不计入时间账本。虚线前灰色包含空闲、排队和控制。灰底→红色活动区间→各类别计算色覆盖。混批紫色只表示共同计算。图层、批次、step 不是相同计数单位，不能凭色块数推导批次数。放大图另存，不替代完整图。

### 利用率

主指标=每设备纯计算时间/该次运行 makespan。IO 等待不计入计算。若使用有效窗口或其他分母须显式说明，不能与原口径混用。热力图列按原设备编号，不沿用时间线的独立排序。跨方案保持 0–100% 色标；箱线与热力图使用同一组逐设备数据。

### 带宽

横轴 ms，纵轴 GB/s（十进制 10^9 B/s）。默认保留原版对数纵轴，需求橙线、实际蓝线、容量黑虚线。容量来自本次配置，不固定为 120 GB/s。有事件区间时按区间与时间桶重叠长度积分，原版桶宽 10 ms；不能对不等长事件直接算术平均。验证实际速率积分与读取字节一致。零值 CSV 保留 0；对数显示底线注明只影响绘图。需求超订按 demand>B，实际饱和按 actual≥0.9B；阈值若变更则明确写出。所有方案共用时间范围与纵轴。换用线性轴需有可读性理由并注明。

### CDF

TTFT=first_token−arrival，包含中央准入等待。经验 CDF 使用排序样本与 rank/n 的阶梯线，x 从 0 起，y 为 0–1。总体图可以叠加期限宽度分布；分类期限相同时画点状竖线，不同时画期限分布或标注差异，不能虚构单一阈值。不要用总体 TTFT CDF 与期限 CDF 的相交位置直接推导 SLO：期限因请求而异时按请求匹配计算是否达标。输出排序值、排名和 CDF 数值，检查单调性及终点 1；说明分位数算法。

## 验证与交付

保留实际完成的检查与误差阈值。报告中的旧检查数量不是新任务的要求或结果。验证清单按本次数据适用性选择：逐运行汇总与原始请求对照、分类计数、时间账本、带宽积分、CDF 概率质量、生成文件 SHA256、文档相对链接、PNG 可读性及 ZIP 内文件一致性。

目录：主报告 `实验结果-<主题>-<YYYYMMDD>.md`；`figure/`；`report_data/`；生成脚本及所需样式模块；主题与日期命名的 ZIP。每个已交付文件只列入 ZIP 一次，不包含 ZIP 自身和无关数据。保持数据来源可追溯，明确复现所需的原始资产，不能将汇总 CSV 宣称为完整原始事件记录。
