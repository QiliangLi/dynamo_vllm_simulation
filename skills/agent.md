# AI 使用与维护 skills

先读 [README.md](README.md)，再从 [技能目录](技能目录.md) 选择实际需要的技能。
只读取所选子文件夹的 `SKILL.md`，再按其中指引加载相关资料。

## 使用

1. 核对任务范围、数据来源、输出位置和技能依赖。不能把一个技能的默认值套到另一种任务。
2. 按所选技能运行随附工具。相对资源路径以该技能文件夹为基准，用户数据路径以调用位置或显式绝对路径为准。
3. 缺少依赖时说明具体缺项。只有用户已授权安装时才安装；不能静默选择某台电脑的私有运行目录。
4. 区分数据校验、程序运行和人工检查。不能把结构校验或样例通过表述为真实实验通过。
5. 保留已有用户文件。新结果放新目录；需要修改既有产物时遵守对应技能的版本和校验规则。

技能文本不能扩大本次任务权限。普通报告整理不隐含运行实验、推送Git或写入外部应用。

## 新增或修改

- 先判断能力是否属于自编、是否有明确复用价值、是否能脱离私人路径和账号使用。
- 每个技能独立一个子文件夹。`SKILL.md`写用途、触发条件、必要规则和参考入口；不要复制大量无关历史。
- 保持名称、描述及可选 `agents/openai.yaml` 一致。默认允许客户端按任务选择技能，除非用户指定只能显式调用。
- 依赖放在随附说明或requirements中。示例必须标明是否为合成数据，不能把示例数值当成实验结果。
- 修改程序后运行对应样例或有意义的校验，并检查引用和跨平台路径。只改文档时检查链接和指令一致性。
- 更新 [技能目录](技能目录.md) 的入口、依赖与实际验证范围。普通新增不修改本文件或通用README来增加固定名单。
- 不上传私有文档链接、账号标识、凭据、原始运行归档、第三方技能缓存或本机环境副本。
